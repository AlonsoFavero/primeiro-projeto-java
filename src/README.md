# ☕ Primeiro Projeto Java

Projeto desenvolvido durante meus estudos de **Java**, com foco nos fundamentos da **Programação Orientada a Objetos (POO)**.

O objetivo deste projeto foi praticar os principais conceitos da linguagem por meio de exercícios independentes, organizados por assunto, buscando construir uma base sólida para posteriormente desenvolver aplicações **backend com Java e Spring Boot**.

---

## 🎯 Objetivos

* Desenvolver uma base sólida em Java.
* Compreender os principais conceitos de Programação Orientada a Objetos.
* Praticar a criação e organização de classes e objetos.
* Entender como os diferentes recursos da linguagem funcionam na prática.
* Desenvolver boas práticas de organização de código.
* Preparar uma base para estudos futuros em desenvolvimento backend com Java.

## 📚 Sobre o aprendizado

Este projeto representa uma etapa inicial da minha jornada no desenvolvimento com Java.

Durante os exercícios, pratiquei conceitos importantes de POO e procurei entender não apenas a sintaxe, mas também **quando e por que utilizar cada recurso**.

Alguns exemplos trabalhados:

* Utilização de **encapsulamento** para controlar o acesso aos atributos.
* Utilização de **herança** para representar relações entre classes.
* Utilização de **polimorfismo** para trabalhar com diferentes implementações.
* Utilização de **interfaces** para definir comportamentos.
* Utilização de **composição** para representar objetos que possuem outros objetos.
* Utilização de **sobrecarga** para permitir diferentes formas de utilização de um mesmo método.
* Utilização de **`static`** para membros compartilhados pela classe.
* Utilização de **`final`** para impedir alterações após a definição de um valor.
